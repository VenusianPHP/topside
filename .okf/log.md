## 2026-11-25

* **Update**: [Window lifecycle](/architecture/window-lifecycle.md), [Mail](/architecture/mail.md), [Views](/architecture/views.md): alerts. `ToolkitPoweredWindow::alert(Alert)` returns an id and the answer is `AlertAnswered` (-1 when the window closed first); `Alert` and `AlertStyle` are ported from the bridge-era dialogs contract, with no capability checks: a toolkit leaves out what its alert has no place for. A button takes padding (`setPadding()`, `applyPadding()`, `padding` in Sharp). 685 tests on NTS and ZTS.

* **Update**: [Primitives](/architecture/primitives.md), [Views](/architecture/views.md), [Sharp](/architecture/sharp.md): a label's text can be runs (`TextRun`, `setRuns()`, `applyRuns()`; `<b>`, `<i>`, `<span color>` inside `<Label>`); every primitive takes `maxSize()` (`applyMaxSize()`); a button its `iconPosition` (`IconPosition`, `applyIconPosition()`). A component is mounted with a `Mount`: `$this->window()` and `$this->refresh()` beside `$this->navigator()`. 672 tests on NTS and ZTS.

* **Update**: [Primitives](/architecture/primitives.md): a transition given no time runs 0.3 seconds (`TKTransition::DEFAULT_SECONDS`).
* **Update**: [Primitives](/architecture/primitives.md), [Sharp](/architecture/sharp.md), [Mail](/architecture/mail.md), [Views](/architecture/views.md): a group can be clickable (`setClickable()`, `applyClickable()`, `GroupClicked`), so `@click` works on every container. `TKTransition` gains `MOVE_RIGHT`, `MOVE_LEFT`, `MOVE_TOP`, `MOVE_BOTTOM`, travelling the primitive's own size with no fade, and `DEFAULT_SECONDS`; `appear` and `disappear` are Sharp attributes, and a primitive built hidden plays nothing. 653 tests on NTS and ZTS.

* **Fix**: [Views](/architecture/views.md): a navigator belongs to the window that shows routes.
